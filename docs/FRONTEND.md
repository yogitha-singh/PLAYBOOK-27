# FRONTEND (Phase 3) — what exists, and exactly what was and was not verified
**Stack:** dependency-free HTML + CSS + ES modules, hand-written SVG charts, served by the Flask app at `/`. (React/TypeScript/Vite/Tailwind/Recharts were specified but cannot be installed offline; see ARCHITECTURE.md.) No build step. No web fonts are loaded (CSP is `self` only): the font stacks name Space Grotesk/Inter and fall back to system fonts, so the intended typography appears only if those fonts are installed.
**Design system:** `css/tokens.css` (colours #EA1A85 / #0A1F44 / #FFFFFF / #FCE8F2 / #FAF9FB / #E8EAF0 / #20243A, type, spacing, radius, shadow, chart series), original SVG logo and favicon (`assets/`), reusable components (`js/components.js`): KPI cards, cards, callouts, tier/confidence/type badges, sortable tables, pager, skeleton, error box, toasts, dialog.
**Modules (hash routes):** `#/overview` Command Centre · `#/pressure` Pressure Explorer · `#/batters`, `#/bowlers` intelligence + scouting-card dialog · `#/compare` · `#/leaderboard` · `#/auction` (shortlist, notes, balance, alternatives, exports, API-key entry) · `#/scenario` (three separately labelled layers) · `#/models` · `#/about` (methodology, validation, limitations, system status). Brand-pink text is avoided on white (4.21:1); `--pink-ink` is used for text.
## Verified (automated, executed)
* `node --test` — 21 tests: all pages' `load()` + `view()` run against the **live Flask API** for every route variant (all sort keys, filters, both roles, all model tasks, all scenario presets, empty/error states, 2- and 6-player comparisons); no `NaN/undefined/[object Object]` in output; every embedded SVG is well-formed; hostile strings (`<script>`, `<img onerror>`) are escaped in cards, notes and charts; card pressure-delivery/legal-ball counts equal the ranking-table values for top players; chart functions survive empty/NaN/single-point data; router parsing; WCAG AA contrast of every text/background token pair.
* Python contract tests: every API call in the JS maps to a real backend route/method; every JS import and HTML asset resolves; correct MIME types; no inline scripts/handlers (CSP-compatible); no hard-coded hosts/secrets.
* A bug found by this process: `/methodology/validation` emitted `NaN`, which browsers' `response.json()` rejects — fixed in the pipeline (strict JSON) and the API (NaN→null), with a regression test over all JSON endpoints.
## NOT verified (no browser is available in this environment)
Visual appearance and polish; responsive layout at tablet/mobile widths; the off-canvas menu; the `<dialog>` scouting card behaviour; focus management and keyboard navigation; screen-reader output; toasts; **all `mount()` event wiring and `app.js` DOM code** (these were only syntax-checked, not executed); print styles; cross-browser behaviour. Expect some visual/interaction defects on first real use — please open the app and report them.
